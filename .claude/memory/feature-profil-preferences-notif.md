- Axe A = **A1** : page `/mon-profil` ciblée sur le parent connecté (résolu via `moi.email`),
  réutilise l'existant, **zéro nouveau champ / zéro migration parent**.

  - désabonnement one-click **RFC 8058** (endpoint `@Public` signé, table `desabonnement_token`)
  - inbox in-app générique (table `notification` lu/non-lu).
- Validation hebdo = notif **de service** : canal configurable mais **≥ 1 canal actif obligatoire**
  (jamais coupée totalement). Récap au service (établissement) non désabonnable côté parent.
- Préférences vivent dans **svc-foyer** (agrégat parent) → event `foyer.PreferencesNotifModifiees.v1`
  projeté vers svc-notifications (durable `notifications-preferences`, stream `FOYER`) → **zéro Pact**.
