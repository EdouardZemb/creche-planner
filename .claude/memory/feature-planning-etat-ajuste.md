Chantier en **3 phases** pour lever l'ambiguïté du planning : aujourd'hui il affiche « Absent » dès qu'une absence existe sur un jour gardé, même quand ce n'est qu'un ajustement partiel (départ avancé / arrivée retardée). Une absence = fenêtre horaire `PlageHoraire` (`debut→fin`) ; durée facturée = `fin − début`.

- Renvoie `{ statut: 'absent'|'ajuste', libelle, presence: string|null }`. Branches (minutes depuis minuit, A/D=contrat, a/d=absence) : `plageContrat===null`→Ajusté/null ; `a≤A && d≥D`→Absent/null ; `d≥D && a>A`→« Départ avancé »/`arrivée–a` ; `a≤A && d<D`→« Arrivée retardée »/`d–départ` ; sinon (fenêtre intérieure)→Ajusté/null. Tiret demi-cadratin « – » (U+2013).
